英文課筆記本 Gemini 版｜快速啟動

檔案：
- 英文課筆記本_Gemini版.html：已接上本機 API 的網頁
- server_gemini.py：本機 Python 後端，安全保管 API Key

第一次使用：
1. 到 https://aistudio.google.com/app/apikey 建立 Gemini API Key。
2. 把 ZIP 解壓縮；確認 HTML 和 server_gemini.py 在同一個資料夾。
3. 在 Mac 開啟「終端機」(Terminal)。
4. 用 cd 指令切換到解壓縮後的資料夾。例如若資料夾在下載項目：
   cd ~/Downloads/英文課筆記本_Gemini串接檔案
   （若資料夾名稱或位置不同，請改成實際位置；也可以先輸入 cd 後空一格，再把資料夾拖進終端機，按 Enter。）
5. 執行：
   python3 server_gemini.py
6. 終端機詢問 Gemini API Key 時，貼上金鑰後按 Enter；若只要保存筆記，可直接按 Enter 略過。輸入時畫面不會顯示字元，這是正常的。
7. 瀏覽器開啟：
   http://127.0.0.1:8000/英文課筆記本_Gemini版.html

日常使用：
- 先啟動 Terminal 中的 python3 server_gemini.py
- 再用瀏覽器開啟上面的網址
- 關閉伺服器時回到 Terminal 按 Ctrl + C

筆記透過本機後端保存到同資料夾的 notes.sqlite3。新增分類筆記、翻譯紀錄、AI 詢問紀錄和刪除都會同步儲存；關閉瀏覽器或重新啟動伺服器不會清空資料。請備份這個資料庫檔案；刪除它會刪除保存的筆記。

也可使用「備份 JSON」下載可攜式筆記備份，再用「匯入」還原。舊瀏覽器中的筆記可在舊網站按「備份 JSON」，再到本機網站匯入。

翻譯使用方式：在筆記本輸入原文，按「開啟 Google 翻譯」；新分頁會帶入原文和目標語言。翻譯完成後複製譯文，貼回筆記本的譯文框，再按「儲存翻譯紀錄」。此功能不需要 Google 翻譯 API Key。

伺服器只監聽本機 127.0.0.1，不需要密碼，適合只在這台電腦使用。GitHub Pages 是靜態網站，無法直接連接這個本機資料庫；若要公開網站或不同裝置共用，還需要把後端和資料庫部署到雲端。

第一次切換前備份舊筆記：
- 先用原本開啟方式打開舊 HTML，按「匯出」下載 JSON。
- 新版改用 localhost 網址後，瀏覽器會把它視為不同網站來源，舊 localStorage 不會自動出現。
- 新版開啟後按「匯入」，選擇剛才匯出的 JSON，即可搬回舊筆記。

注意：
- 不要把 API Key 貼進 HTML。
- 這個版本只提供本機使用，伺服器只監聽 127.0.0.1。
- 本機後端無法連線時，網站會退回瀏覽器 localStorage；請留意頁面上方的儲存狀態。
- 翻譯結果由 Google 翻譯網站提供；Gemini 分類與助教對話仍使用 Gemini API。
- 若出現模型不存在或不支援錯誤，請回報錯誤文字，以便調整模型名稱。
